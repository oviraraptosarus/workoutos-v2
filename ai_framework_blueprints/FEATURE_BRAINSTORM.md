# Feature Brainstorm Framework

## Purpose
Generate useful ideas that make Workout OS meaningfully better.

## Brainstorm Rules
- Start from a user problem.
- Generate 5–10 possible solutions.
- Then narrow to the best 1–3.
- Prefer features that connect multiple modules.
- Prefer features that save time or reduce decisions.

## Good Feature Types
- automation
- summarization
- prediction
- reminders
- cross-module actions
- progress insights
- AI-assisted planning

## Avoid
- cosmetic features with no workflow value
- duplicate app features that other apps already do well
- features that need large backend work for small benefit

## Output Format
For each idea provide:
- idea
- user value
- why it is different
- dependencies
- risk
- whether it should be built now
