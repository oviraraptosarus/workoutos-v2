# Feature Scoring Framework

Score each idea from 0–10 on:

- User Value
- Daily Usefulness
- Differentiation
- AI Advantage
- Cross-Feature Integration
- Maintainability
- Revenue Potential
- Simplicity

Use inverse scoring for:
- Development cost
- Backend complexity
- Maintenance burden

## Thresholds
- 80–100: build now
- 60–79: consider later
- below 60: reject or rethink

## Final Rule
A feature only moves forward if it is clearly valuable and fits the system.
